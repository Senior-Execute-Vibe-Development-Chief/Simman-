# IPA phone recordings — attribution

The Language Lab's **recorded phones** voice plays one human citation
recording per base IPA phone (`assets/ipa-audio/`, keyed by symbol in the
generated `src/sim/ipaAudioManifest.js`). The recordings are used as-is —
playback only, per phoneme; word and sentence audio remains the Lab's own
synthesizers (`src/sim/vocalTract.js` and the formant sketch), because
isolated citation phones do not concatenate into connected speech.

## Source — Wikimedia Commons

- **Source:** [Wikimedia Commons](https://commons.wikimedia.org), the audio
  set behind most interactive IPA charts (in large part Peter Isotalo's 2005
  recordings, with later contributors filling the table).
- **Licence:** per file — a mix of **CC BY-SA** (various versions) and
  **public domain** dedications. `assets/ipa-audio/SOURCES.tsv` records the
  exact licence, author, and Commons description page for **every** file;
  it is regenerated by the fetch tool, never hand-edited.
- **Modifications:** none. Files are stored byte-identical to the Commons
  originals, renamed to codepoint slugs (e.g. `0070.ogg` for [p]) so the
  mapping is mechanical.
- **Tool:** `tools/build_ipa_audio.mjs` — enumerates the phone space from the
  generator's own feature grids, resolves titles through the Commons API
  (which is also where the licence metadata comes from), and downloads with
  throttling. Re-runs are incremental.

## Why not the chart that inspired this

The bank was prompted by Haakon S. Krohn's excellent
[interactive IPA chart](https://haakonkrohn.com/ipa/) — but that site's
recordings carry a plain "© Haakon S. Krohn" with **no reuse licence**, so
they cannot be redistributed here. The Commons set provides the same
coverage under explicit licences. (If permission from the author were ever
obtained, the fetch tool's mapping table is the single place a different
source would plug in.)

## Attribution in the app

The Sound card credits the recordings inline (`IPA_CLIP_CREDIT`), and this
file plus `SOURCES.tsv` carry the per-file detail. CC BY-SA files remain
under CC BY-SA; nothing here relicenses them.
