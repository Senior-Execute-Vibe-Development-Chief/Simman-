# SIMMAN CORE SIM DOSSIER — inventory for the v2 rebuild spec

Scope: `src/sim/peopleSim/{state,popField,settlement,crystallize,conquest,countryTerritory,territory,armies,roads,sea,transport,foodHierarchy,tech,faiths,cultures,dynasties}.js`, `src/sim/pipeline.js`, `src/sim/persist.js`, `src/peopleSimWorker.js`, plus the modules those pull state through (`index.js`, `rng.js`, `entities.js`, `tuning.js`, `tech.js`, `loyaltyField.js`, `landKnow.js`, `identityField.js`, `calendar.js`, `inflation.js`, `transport.js`).

**Orientation.** `pipeline.js` is not the sim tick — it is worldgen stage 2 (rivers, floodplain ribbon, crop suitability `tCrop`, crossing overlay `tCross`, resource deposits, and the deep-ancestry peopling simulation). The sim tick lives in `peopleSim/index.js` (`stepPeopleSim`). Units: 1 sim-person = 1,000 people (`POP_SCALE`); `popField` is a separate internal scale bridged by `world._onePopScale`. Reference grid `tw=240`; app ships `tw=960`. The shipped default regime has essentially the whole "field stack" ON: `POP_FIELD, ONE_POP, DEV_FIELD, FIELD_DEMOG, FIELD_POLITY, TILE_POLITY, FIELD_ADMIN, CATCHMENT_CLIP, SIZE_BY_POP, DISSOLVE_FARMS, DISSOLVE_TOWNS, CITY_AT_BIRTH, DAWN_LIVE, INVENT_JUMP, CITY_CORE, ONE_BOOK, MARKET_PULL, TILE_MONEY, GRAIN_MARKET, HARVEST_YEARS, LAND_KNOW, STATE_RECORDS, STATE_OF_LAND, LOYAL_FIELD, GRIEV_LEDGER, SUCCESSOR_STATES, WAR_FINISH, PEER_LATTICE, PEER_SEATS, FISSION, CONTROL_FIELD, MULTI_HEARTH, INVENT_STAGGER, RES_INVARIANT_POP, TECH_EFFECTS=1` all default 1. Notable default-0: `LABEL_BIRTH`, `MARGINAL_HOLD`. The legacy pre-flip world remains reachable byte-identically by pinning levers off (persist.js encodes 60+ such regimes).

## 1. STATE INVENTORY

### 1.1 Per-TILE fields (length N = tw×th unless noted)

**Static terrain — derived once at `createWorld` from worldgen, never persisted, deterministically rebuilt on load:**

| field | type | meaning |
|---|---|---|
| `elev, temp, moist` | f32 | point-sampled from worldgen pixels |
| `fert` | f32 | **max-pooled** over the tileRes block from `tCrop` (point-sampling dropped the Nile ribbon) |
| `relief` | f32 | max-pooled local vertical range (`computeRelief`) — the ridge term in edge cost |
| `tFlood` | u8 | arid-river floodplain mask (block-OR of pipeline mask); marking also floors `moist` at 0.45 |
| `coast` | u8; `riverMag` | u8 max-pooled river magnitude 0–4 (max-pool restored ~64% of river tiles lost at tileRes 2) |
| `deposits{timber…dyes}` | f32 each | 14 tracked resources, point-sampled |
| `ancestry` | i16 (−1 none) + `tArrival` f32 | deep-ancestry lineage id and normalized peopling-wavefront arrival time (from pipeline.js `generateAncestry` — a full Dijkstra peopling sim with beachcomber coasts, ocean-distance exponential, residence-time fissioning) |
| `_windX/_windY, _tAmp/_warmRainFrac, _dryFrac/_summerDry` | f32 | seasonal/wind carries (underscore ⇒ never persisted) |
| derived caches | | `_floodTiles` list, `_popLand` (land index), `_coastList`, `_tileValue` (fert ∨ FLOOD_VALUE 0.9 ∨ RIVER_VALUE 0.55), `_rmBand/_coastBand` (ACCESS_BAND real-width water bands), `_rivNear`, `_irrigable`, `_pastureCap`, `_tropicBurden`, `_devClim` (zone-smoothed climate), `claimNoise`, canopy mask, `_agriCeil`, cage field, `_km2PerTileW` |

**Demographic fields (the v2 heart):**

- `popField` f32 — people-on-land, per-real-area units (seed/cap ÷rn²). **AUTHORITATIVE demography under ONE_POP; SAVED** (an integral of history, not re-derivable).
- `capField` f32 — carrying capacity. **DERIVED every field firing** (fert × dev × access × relief × works × industrial…, plus urban spikes); not saved.
- `_popNext` f32 — migration double-buffer (swap pair; under the worker pool a fixed SAB pair with parity).
- `devField` f32 — regional agricultural technique (wave-of-advance ratchet). **SAVED** + `_devWaveAt` cadence clock; `_devSrc`, `_devNext` scratch.
- `worksField` f32 0..1 — Boserupian built land capital (`LAND_WORKS`). **SAVED**.
- `_urbanSpike` Map(ti → {k, r, sink}) — per-tick city-core capacity/growth-rate stamps; rebuilt each derive.
- `_soilFatigue` f32 (sparse-saved) — salinisation memory ("the land remembers"); `_fishTaken` f32 (sparse-saved) — fished-down fraction of coastal stocks ("the sea remembers").
- `_harvestZ` — ~450-cell coarse annual harvest-z grid (SAVED); per-tile `_yieldCv/_yieldDeep` derived.

**Political fields — four coexisting layers plus one economic layer (a major v2 consolidation target):**

- `_countryOwner` i32 — **THE political map** (country id per tile, −1 wild). Authoritative; saved. Authored by `fieldPolityTerritory` each territory pass.
- `_countryClaim` i32 — the render **crawl** toward `_countryOwner` (`relaxClaim`); saved; render-only under TILE_POLITY.
- `_ctrlOwner/_ctrlHold` — control-field "pretty borders" (CONTROL_FIELD); render-only, not saved.
- `_landOwner` i32 (sparse-saved) + `_landSeats` Map — tribal "nations of the land" static basin territory (STATE_OF_LAND).
- `_territoryOwner` i32 — **economic catchment partition** (settlement id per tile; who farms/markets each tile). Authoritative for food/resources; saved. Plus `_territoryCost` (bid effort), `_territoryTrueCost` (haul cost), scratch snapshots (`_terrFarmSnap*`, `_terrPrevOwner`, hysteresis second-best lanes).
- `_tileCapturedAt` f64 default −∞ (sparse-saved) — conquest hold clock.
- Loyalty field (LOYAL_FIELD): `_allegiance` f32 (saved), `_tileOwnerPrev` i32 (saved), `_tileHomeland` i32 sparse, `_tileFellAt` f64 sparse — the land's memory of fallen nations; feeds restoration and unrest.
- `_tileWealth` f32 (sparse-saved) — farm-gate coin on worked tiles (TILE_MONEY).
- `_claimPress` f32 (saved) — crawl pressure.

**Roads:** `roadQuality` f32 (1.0 = no road; painted at builder roadcraft, packs to 0.30, paves to 0.12/0.08 as the owning realm earns Roads/Railroad; decays when idle) — saved. `roadFlow` f32 decaying-EMA traffic — saved. Sparse indexes rebuilt by `reindexRoads`; `_tileComp/_tileCompSeen` network components (render).

**Identity field:** `tileCulId/Shr`, `tileFaithId/Shr`, `tileLangId/Shr` (i16/u8 × K=4 slots) — Stage-0 mirror of settlement mixes, diffused for the active lens only; render-only today.

### 1.5 Dual representations (explicit list)

1. **Census vs field:** `s.people` = Σ`popField`(catchment) × `_onePopScale`. The bridge is frozen at first derive (global Σcensus/Σfield; dawn variant: `FORAGER_EARTH_CENSUS=5000` su ÷ Σ pristine field; last-resort `BRIDGE_REF=0.002`), persisted, never re-derived.
2. **Urban core, three ways:** `_urbanPop` (overwritten by ruralShare heuristic mid-tick, then by the field measurement), `_coreMeasured` (the authoritative field read), and `min(econF, disk)` economics clamps in `deriveOnePop`.
3. **Political ground, four layers:** `_countryOwner` (authoritative) / `_countryClaim` (crawl) / `_ctrlOwner` (pretty) / `_landOwner` (tribal), merged only at render.
4. **Economic vs political ownership:** `_territoryOwner` vs `_countryOwner`, cross-clipped via CATCHMENT_CLIP (with CATCH_GRACE dispute timers) and read back by SIZE_WORKED.
5. **Food, two books:** the settlement grain ledger (`_foodSupply/_foodDemand/food`) vs the field (`capField/popField`) — bridged by ONE_BOOK (demand bills the urban core only), FOOD_K (worked land's capacity IS the ledger, blended by administrative reach), and WAR_FINISH ("the land feeds them" OR-gate on desertion).
6. **Knowledge, three carriers:** entity `knowledge` tracks, `devField` (agriculture on the land), `_landKnow` ledgers (pre-urban basins), plus the derived discrete tech tree (`techState`) and its effect channels (`techEffects`) blended by `TECH_EFFECTS`.
7. **Realms, two records:** `countries` view vs `polities` registry (fiscal/temperament state lives only on the registry).
8. **Money, two pockets + field:** settlement `wealth`, polity `treasury`, and `_tileWealth`; conservation enforced across all three (ruin hoards, seigniorage, farm-gate credit).

## 2. PASS STRUCTURE (the tick, `index.js stepPeopleSim`)

`SIM_GRANULARITY` G: `world._dt = 1/G`; rate passes stretch intervals ×G (`_ivl`), recompute passes don't. `_at(base, phase)` offsets heavy passes onto distinct primes to avoid mega-ticks (measured 174→1197ms stacking). Order per tick:

1. `step++`; rebuild `_byId` (reused Map), settlement grid; `_popTotal`; `_leadOrg/_civYear` (1-tick-stale read of leading capital org).
2. **Climate** (`CLIMATE_INTERVAL=20`, rate): century walk + eruptions → `climMod` fertility overlay. **Harvest years** (`HARVEST_INTERVAL=2` ≈ every year): regional annual z-grid → `_harvestYearMul`, famine derives from the tail.
3. **Territory block** (every `TERRITORY_INTERVAL=144 × rNorm` — cadence stretched at fine grids; 63–203 s/firing at 1920 was 97% of compute): `computeTerritory` (economic catchments, MARKET_PULL bid Dijkstra + tally) → `computeCountryTerritory` (= `fieldPolityTerritory` under FIELD_POLITY: the 7-step political field) → `resolveOrphanedMarches` → `adoptAndFound` → `nucleateFrontierStates`.
4. Border crawl `relaxClaim` (every 3 ticks under TILE_POLITY; render-only).
5. `stampLandHarvest` for all settled; `poolFoodHierarchy` (levy + tree purchase + open grain market) — **same-tick imports before the ledger**.
6. **Settlement loop** `updateSettlement` per settlement: food → population (+tier per-tick) every tick; the heavy economy (wealth, coerced labour, goods, development, knowledge) on `SETT_STRIDE=3`, phase-staggered by id, dt×K. Profiled: this loop is ~65% of a dense tick (knowledge 23ms, goods 22ms, food 18ms per tick at 535 cities pre-stride).
7. `urbanise` (legacy census drift; no-op under ONE_POP).
8. **popField pass** (`POP_FIELD_STRIDE=1`): `stepPopField` — capacity → forest/tillage/cradle post-passes → FOOD_K blend → urban spikes → logistic growth (local regimes) → migration substeps → LAND_WORKS build/rot. ~44% of a dense tick; optional worker-pool banding (bit-identical by construction). Then `deriveOnePop` (census from field, agglomeration flow, spike stamps).
9. `aggregateFoodHierarchy` (scarcity prices for next cadence). Control field stride 4 (render).
10. `updateShocks` (famine windows legacy-arm, epidemics along trade graph); `maybeCrystallize` (internally: dissolution, landKnow growth, site cities, land nations, then every `CRYSTAL_INTERVAL=24` the transport refresh (480), colonies (240×G), urban genesis (120×G), plantations (480×G), spontaneous sweep).
11. `maybeBuildRoads` (plan every 240; reach rebuilds staggered over 120 ticks); `updateInflation` (50); `updateTrade` (stride 5, ×5 volumes).
12. `musterArmies` (`MUSTER_INTERVAL=100`, phase 23); `advanceFronts` (`CONQUEST_INTERVAL=50` ×G).
13. `moveShips` every tick; `updateSea` (600, phase 7).
14. `updateSoil` (600, phase 11); `updateFishStocks` (50, phase 13, un-stretched).
15. `updatePolities` (`POLITY_INTERVAL=150`, phase 37) — the whole politics stack (§3.8-3.9).
16. `updateCultures` (150/41), `updateFaiths` (150/43), `updatePilgrimage` (50/47), `updateSlaveTrade` (50/53), `updateDynasties` (25/59).
17. Identity-field diffuse (only when a lens is open, 150), `chronicleTick` (300), `foldMoney` per settlement, optional invariant check; `pruneDead` every 32.

**Worker interface (`peopleSimWorker.js`):** messages in: `init` (worldgen product + tCrop/tFlood/ancestry/deposits), `control{playing,speed,autoEpoch}`, `visibility`, `select/selectRealm/view/chronicle-mode/dynasty-open`, `settTrace`, `save/load`, `tune{values,reset}`, `editor.placeCountry` (drops a fully-formed realm then bursts 640 steps), `mapFilter`, `scrub`, `export*`. Out: `snapshot` ~30 Hz (2 Hz under fastEpoch/hidden) with per-settlement mirror records (`packSettlement`), full detail for the selected one (`packSelected`), realm list, chronicle (re-narrated only on change), incremental event feed, and transferable per-tile overlays (owner/roadQuality every 6th snapshot, roadFlow per frame, lens-specific popDens/devDens/loyal/identity/coin arrays on absolute rulers). Self-scheduling via MessageChannel with a 12 ms step budget; "quiet ages" auto-max speed until the first realm exists (reads realm count, not the calendar); snapshot buffer pool with `bufret` round-trip (the 26.6k allocation-wall fix); sim errors pause but keep the world alive for save/rescue; run journal + telemetry funnels every 250/1000 steps.

## 3. MECHANISMS PER SYSTEM (the rule, not the code)

### 3.1 Population growth & migration (popField.js)
- **Capacity:** `cap = fert_eff × (CAP_PER_FERT/rn²) × (DEV_BASE + DEV_TECH·dev_local) × (1 + access·(ACCESS_DEV0 + ACCESS_DEVK·dev)) × reliefMul × indMul × worksMul`, where access = river/coast bands over a real width (ACCESS_BAND, sum-capped under BAND_SUM); then post-passes: TILLAGE workability × metallurgy, FOREST_LOCK canopy lock (Köppen mask) × iron, FIELD_CRADLE irrigation/alluvium lift (same constants as the settlement food law), all floored by pastoral rangeland `openness × CAP_PER_FERT × 0.10` (max(crop, range)); finally FOOD_K blends worked tiles toward the settlement's real food ledger (`s._k × landShare / bridge`, distributed ∝ proxy quality, downward authority gated by `foodReach` — the org ramp).
- **Growth:** per-tile logistic `p += r·dt·p(1−p/cap)`; `r = SETT_GROWTH(0.0007)` under ONE_POP, modulated by GROWTH_LOCAL regime `(R_DEV0 + R_DEVK·dev)/(1+R_TROPIC·burden)`; city-core tiles re-integrated with their own stamped rate `r_eff` (demographic transition bend: `r×(1−0.85·min(1,urbShare/0.5)·literacy·fed)`) minus a **flat graveyard sink** (`SETT_GROWTH × 1.2 × diseaseLoad × min(1,urbShare/0.3) × (1−healthRelief)`, density-graded ^γ vs the median core under URBAN_GAMMA).
- **Migration:** each substep a tile sends `migShare·p` split among 4-neighbours ∝ spare capacity (cap−pop); total share per firing = `POP_MIGRATE·dt·rn²` split into substeps ≤ 0.5 (diffusion-coefficient res-invariance; byte-identical at reference). Double-buffered.
- **Urbanization** = anti-diffusive concentration (`deriveOnePop`): each city's target `uTarget = URBAN_AGGLOM(0.13) × (1+URBAN_IND·indGate) × ΣK × share`, `share = pull^β/Σpull^β` (β=1 under γ; pull = whole economy `s._k/scale` under AGGLOM_LOCAL); relax core toward it at λ=0.2/tick via strictly conserving town↔country moves within owned tiles (`urbanConcentrate`), capped by hinterland share (0.9/0.97) and by the food gate (bisection: taking a farmer must not leave core need uncovered). Stores never raise the target (`_fedM` holds a stocked core; empty pot melts).
- **Demographic events** (`fieldShift`): every census add/remove mirrors onto the field (gains at home tile; losses ring-cascade outward, clamped).

### 3.2 Founding / crystallization / dissolution (crystallize.js)
Under the shipped regime (`CITY_AT_BIRTH`), the spontaneous sweep mints **nothing**; genesis is the site lane:
- **Site ledger** (`buildSiteLedger`, static, deterministic): Class N river nodes off the pixel flow tree (confluences with ≥2 branches ≥60e3 km², ocean mouths, terminal sinks) + Class H anchorages (shelter ≥ 0.30 of the half-horizon disk, local maxima), greedily quantized at half a market horizon; every tile assigned to nearest site within `TOWN_BASIN_R=10` ref-tiles (the cell partition). Measured resolution-invariant (~±5% across grids).
- **Eligibility per site:** unclaimed cell; cell mass ≥ `(TIER_CORE[2]/URBAN_SHARE_REF)/bridge × leanAt(ti)` — i.e. a 10k-person core at the measured ~5% pre-industrial urban share needs a ~200k-person basin, times the basin's own once-a-century bad-year margin `1/max(0.2, deepYear)` from the validated yield-variance map (LEAN_YEAR); the peopled basin (walkable BFS take) must farm (people-weighted devField ≥ NEOLITHIC_AGRI); CITY_STORE: a basin's worth of people must stand on storable-capable ground; MINT_RESIDUAL: only unmarketed countryside counts; MINT_REACH: the bar must also hold within a day-one court's own reach.
- **Gather:** URBAN_DRIFT = 5e-5/step of the qualifying basin trickles to the site tile, paced by core capacity headroom (min(demand, headroom) — the death-pump fix), held every tick by a spike capped at 1.2× the core bar.
- **Mint:** when the core disk holds `TIER_CORE[2]/bridge` field-people AND the basin's landKnow ledger has crossed the tally bar (`URBAN_ORG=0.28`), `mintCityAt` births a tier-2 CITY; people are debited from the field and re-credited as the census; knowledge is seeded from the ledger; politics from the ground (BORN_OF_LAND: owned ground → that realm; else stateless). Peer lane (`maybePeerSeats`) seats additional courts per cell up to `⌊mass/bar⌋`, spaced ≥ 2×coreR.
- **Tribal nations** (`maybeLandNations`): at unclaimed sites where the basin holds `TRIBAL_CENSUS=10` census of walkable farming people and the ledger can count, formation fires under pressure: contact drive (adjacent state ground), else Carneiro drive = `cage(seat) × storableShare`, through the ORG_CONTACT re-base and a deterministic per-seat hash roll. Territory = the founding basin's take painted into `_landOwner`. **Fission**: a land nation with ≥2 bars of people splits along an organic two-seed walk when a hazard roll fires; both halves must clear the bar. **Materialisation**: a city adopting a land nation's id converts it to a realm (`polity.tablet`), its ground passing via the drawn layers.
- **Dissolution** (`maybeDissolveTowns`): a settled entity dies (mode="dead", wealth → ruin hoard) if its basin < 0.6× the founding bar **or** its urban core < `TIER_CORE[2] × DISSOLVE_CORE(0.2)` **sustained** 1500 history-steps (per-settlement stride 200). People stay on the land (ONE_POP).
- **Other channels:** daughter colonies (`sendSettlers`, pressure-gated, range 28, statecraft symmetry), state plantations (charter towns, treasury-funded), urban genesis (legacy tier-0 regions birthing towns), sea colonies/charters (§3.11), hearth ignition (INVENT_STAGGER: armed hearths mature on peopled-basin time, `T_i = domLagY(package)/suit`; stood down if colonized first). `jumpToCivReady` (INVENT_JUMP × DAWN_LIVE) fast-forwards genesis (field-only stepping + dawn gather) to mint-ready, then holds the mint so play watches the first city rise.
- **Legacy sweep** (CITY_AT_BIRTH=0): random candidates + floodplain oversampling, quality (fert, ×6 river, ×3 coast, resources, chokepoints, defensibility, holy ruins) × (diffusion `e^(−td/30rn)` + independent floor) × package arrival × crowd term × spacing (soft ramp, capacity-scaled) × saturation damper; knowledge inherited from nearest donor, distance-diluted; culture by connection (independent origin / branch / extension; FOUND_DRIFT adds cohesion-reach divergence).

### 3.3 Tiering / urbanization labels (settlement.js updateTier)
Under CITY_CORE + DISSOLVE_FARMS the ladder is **absolute definitions on the measured urban core**: village/town/city/metropolis = `TIER_CORE [0, 2, 10, 40]` census units (2k/10k/40k people); metro bar floats at `max(40, 0.8×largest core)`; demotion below 0.8× the current rung. A core not yet field-measured waits. Legacy arm: percentile bars (P50/P85 of catchment census, floored 60/240) or TIER_BRANCH `cityBar = K×median` (Christaller load ratio). Tier is a **readout**; its old capability grants (haul range, price, hinterland, core radius by tier) are retired under MARKET_PULL/HAUL_PAID.

### 3.4 Food production / hauling / hierarchy
- **Harvest (updateFood):** `landFood0 = netFert × FARM_YIELD_PER_FERT(0.035) × farmYield(tech) × agriGate × armyLabor × eraProd(works×mixedFarm×indCap) × livestock × disease × arid × soil × irrigation × alluvium × (1−cashLand)`; `netFert = (Σ fert·falloff·surplus − farmedWt×FARM_FERT_FLOOR) × ruralLaborShare` (city-dwellers don't farm — URBAN_LABOR). × the year's harvest multiplier. + pastoral calories on graze tiles. Fish: Schaefer catch = fishers × per-capita × tech × abundance, drawing down per-coast-tile logistic stocks; fisher share ramps toward `FISHER_MAX × unmet-need`, withdrawn from farm labour.
- **Demand:** `mouths = urban core` (ONE_BOOK) × 0.003 × urbanFactor + army×0.003 + slaves; `_coreNeed` scoped for famine/siege. Granary integrates supply−demand, clamped at `granaryCap = (80+tier×200)×seasonStore`, spoiling at 0.25%/tick × climate. Famine kill only when flow AND store < core need (FED_FAMINE kills dependents only, ~1.5%/tick). Sieges: a besieged seat's flow is zeroed; it eats stores.
- **Catchments** (territory.js): under MARKET_PULL, the catchment is the outcome of a **bid**: multi-source Dijkstra seeded at `−haulTiles × (offer_i/mean offer)` where offer = min(scarcity willingness, spare-coin ability) and haulTiles = 2×340 km (Diocletian e-folding→linear) × age's best carriage; edges = route cost from the age's best knowledge (shared, fixed-weight graph), value-pulled (`÷(1+VALUE_PULL·tileValue)`); the ring ends where `seed+carriage ≥ 0` (freight eats the price). Owned land is contestable; hysteresis (challenger must be 1.15× better) and flood-signature caching; MARKET_FARM_HOLD keeps worked tiles' haul costs when the flood skips them. Harvest weight `foodFalloff = 1/(1+cost·0.5)` on TRUE haul cost; per-tile land-surplus retention (countryside eats first).
- **Hierarchy (foodHierarchy.js):** post-order over the liege tree; each liege levies `LEVY_MAX×foodReach(org)` of a child's offer in kind, buys the rest at the seller's price out of snapshotted spare coin (closed money); offers = surplus above own demand (SHIP_SURPLUS), decayed by haul survival `exp(−d·spoil/range)` with range = 340 km land / ×12 by an actual sea route, × shipper tech. **Open grain market** (GRAIN_MARKET): coined, unbesieged cities buy deficit + granary refill (≤ demand/tick — the annona) from trade peers' residuals (seed-corn rule: granary refills before exports), highest scarcity price first (GRAIN_BID), buyer pays farm-gate for the whole consignment while the road eats `1/arrive` (GRAIN_FREIGHT); sellers' K gets an export add-back.
- **Carrying capacity:** `K = max(8 people, foodK)` under DISSOLVE_FARMS (housing retired as the cap; `houseK` still computed — drives the import appetite and materials purchases).

### 3.5 Trade / markets / money
- **Money is closed:** minted only from finite `depositReserve` (precious ×150k, gems ×100k per richness) at `MINING_RATE×richness×√pop×org×coerce`, seigniorage share to the treasury; drained by `COIN_LOSS_RATE`; credit (banking institution: `target = specie×(MULT−1)×depth×reach`, crunch ×4 on contraction) and fiat (industrial: output-backed at `_inflRef`, no panic recall) tracked separately in `_credit`. Dying settlements strand coin as `_ruinHoards`, reclaimed when live territory covers them (×org per pass).
- **Export value** (`computeExportValue`, memoized per tick): primary sector (fertility-scaled grain, wild goods, materials, ship goods, fish, horses, salt, log-pop base) + craft legs (Textiles/Metalwork/Pottery/Wares/Services with climate/ore/size gating, idiosyncratic hash edge) with **Ricardian specialty** (score vs lag-1 world-mean output per sector, GOODS_PRICES-weighted) and agglomeration lock-in (`_specKey/_specStr` compounding ×(1+AGGLOM_W·str)); ×(1−armyFrac)×sackPenalty×tradeMult. Under GOODS_UNIFY the manufactured half IS the goods layer's `_gProd` (7-good vector with per-good local prices clamped [0.25,4], stocks, invested capital).
- **Trade pass** (roads.js, stride 5): per reach-pair, food-first, then goods arbitrage (flow ∝ price gap, capped, bulk-weighted freight), general trade along export-value gradients, luxury (supply from territory resources × pop; demand = spare wealth × 1.5%); transit tolls (0.18, ×3 at chokepoints) and border tariffs to treasuries; entrepôt brokerage; `_linkMoney` per link for overlays. **Inflation:** per road-network component, `P = (M/T)/ref` EMA; T = Σ realOutput; baseline `_inflRef` calibrated once when coined money first exists.
- **Fiscal:** wealth tax at variable rate (base→max with war/insolvency), MODERN_FISC income tax on real output × indGate, FARM_RENT produce levy (monetized share as coin, remainder in kind), court share 55% consumed at the seat, disburseTreasury pays army → works/dole; debt with interest and cap; debasement (fineness) as emergency seigniorage.

### 3.6 Tech / knowledge
- **Six continuous tracks** grow by `LEARN_BASE(4.5e-6) × trackWeight × sciMul × headroom × input gates`: construction (materials, metal tools), agriculture (climate spec, wild-forage drag, industrial agronomy break), organization (era-capped by `orgEraCapOf(metalCap, construction)`; literate branch >0.30; circumscription/pressure/contact re-base — statecraft compounds only under Carneiro pressure or a state's example), metallurgy/navigation/mobility (hard resource gates: ore tiers over reachable ore, water, horses; practice vs awareness split — `practisedK` caps effects at `metalCap` while knowledge diffuses freely; sea learning gets demand (dear goods) + fleet (`_seaShare` EMA) terms; saddle-life for pastoralists; horse-free industrial mobility band).
- **sciMul** composes: population (√urban core / SCI_POP_REF), surplus, trade partners, competition (peer-weighted rivals; hegemonic stagnation = decline from peak peer pressure), heritable winter aptitude (`seasonalSelect` cold-winter + dry-summer lobes, ratcheting `_orgApt`), SCI_COMPOUND (knowledge-production index^α through institutions), LABOR_INNOV (coerced labour suppresses), ×dt.
- **Diffusion:** every KNOW_INTERVAL=8 (stride-aligned), pull each track toward the best road+sea neighbour ×litMul ×route-cost damping `e^(−cost/30rn)`, agriculture axis-gated by climate similarity (Diamond), gap capped at ABSORB_STEP (absorptive capacity — the divergence enabler); KNOW_DECAY dark ages on population drawdown/isolation. Crop packages spread by suitability (establish 0.18/domesticate 0.45).
- **Discrete tree** (tech.js): 78-node DAG derived instantly from tracks (`techState` fixed-point), no research economy; `techEffects` sums per-tech channels (farm/military multiplicative revolutions/reach/logistics/health/sci/abilities: embark/ocean/market/credit/walls) with partial credit for imminent techs, memoized on millibucketed tracks (computed FROM the buckets for determinism). `TECH_USE`: site enablers (draft/water/river) zero out unusable techs. Single-definition bars asserted against the tree: `RECORDS_ORG=0.35` (=Writing gate; statehood), `URBAN_ORG=0.28` (=Tallies gate; city/nation door).
- **Pre-urban:** `landKnow.js` per-basin ledgers grow a village-simplified law (agriculture read from devField, ore over a Neolithic exchange sphere, same org pressure lanes), freeze when the cell seats a settlement, and seed the newborn. `devField` wave: settlements/hearth-seeds stamp their agriculture on worked land; one-tile-per-firing relaxation at 1 km/year with planetary thinning and a climate-distance toll (zone-smoothed); genesis pre-run inherits `DEV_INIT_YEARS` (0 under DAWN_LIVE).

### 3.7 War / conquest / armies
- **Garrisons** (`musterArmies` /100): cap = pop×tierFrac (2–11%, org-scaled) using **urban** pop for the professional core; wartime conscript levy from **rural** pop scaled by defensive/offensive load; growth-rate eased; desertion ×0.8 if starved (ledger OR field-fed test), ×0.7 pro-only if unpaid; national manpower pool (frac of pop, regen, drained by casualties) caps deployment.
- **Fronts** (`advanceFronts` /50): under TILE_WAR, country-vs-country over `_countryOwner` via per-realm adapters (national might = Σ garrison×techMul, + vassal levies decayed by reach & loyalty). Attack qualification: power ratio vs bars — exhaustion bar, coalition bar (balance-of-power blocs, relief-reach-weighted backing, ally bar ×4, colonial protection × naval projection), casus belli multipliers (identity era-weighted, succession claims ×0.62, dominance discount), truces (dyadic, extended by mutual trade and war toll). Capture: frontier tiles flip at `CAPTURE_SCALE×advantage` per pass, resisted by terrain hold (river ford ×3.2→2, alpine, ridge — engineering erodes), stamped `_tileCapturedAt`; fronts drain both garrisons (attrition → manpower, war-dead ledger, grievance feed).
- **Storms/sieges:** an assault force (professional share) reaching the defender core besieges: siege works clock (≥60 ticks), endurance vs logistics, walls manned by the urban core (`SIEGE_MOBILIZE=0.2`), SIEGE_STARVE drains the city granary until the famine ratio breaks the militia; storming annexes the city (flips countryId; plunder 30% of coin to victor's treasury, captives, `_sackedAt` production crater healing over 5000 ticks, momentum banked +3/storm), capital storms `fragmentRealm` (successor states, treasury seized). Wars end by truce (exhaustion > 0.4), congress joining, capitulation (decisive gap + 2× network might → `bendTheKnee` vassalage), or stalemate settlements (frozen front EMA).
- **Nomads:** classified per pass (seat in open, unfarmable, horsed country; field variant); momentum counts double and is the state (shatter on succession crisis); raid season vs rich reachable realms (take ≤10% portable coin, captives), `RAID_REACH=2×hold`.

### 3.8 Territory / expansion / admin (countryTerritory.js `fieldPolityTerritory`, 7 steps)
1. **Anchors:** capital home tile only (TILE_POLITY); CITY_HOLD: every settled member anchors + pins a CORE_R core; fallback for un-viewed realms.
2. **Cores stamped** (POP_FIELD path) as `worked`, pinned against shed.
3. **Connectivity/admin walk:** Dijkstra from seats+worked tiles through own land (naval traversal within excursion budget `(1+7·nav)·resScale` consecutive water tiles, per-realm sea distances); unreachable ⇒ SEVERED (released, flagged for successor logic). Yields per-tile admin distance d.
4. **Targets:** `held = Σ loadOfD(d)` where `load = 1 + d/(ADMIN_HALF·resScale)`. Target = `popCap + march`: `popCap = govPop × spanTechMul × RECAL / (RURAL_BIND_DENS/r²)` — governed people (owned + member-worked ground, SIZE_WORKED fixing the self-referential ratchet) at a frozen density constant, discounted by earned span (`1 − 0.85(1−org)` under LAND_KNOW); `march = popCap × MARCH_FUNDED × logistics²`. Nomads keep capacity targets; coverage floor for solo realms.
5. **Frontier growth:** bounded Dijkstra from the frontier into WILD land only, budget = min(rate cap × org-earned rate, target−held), edge cost = transport cost soft-capped by engineering, ×(1+hostility·fertDeficit²) on wasteland, ×wet-tropic drag (fading with logistics), ×organic noise, ×terrain hold at contested crests; claims consume admin load; MARGINAL_HOLD per-tile viability test optional.
6. **Shed:** over-target realms release most-remote unworked edge tiles first (load refunded); marginal release under MARGINAL_HOLD. Rel/relCut masks distinguish SEVERED (political event → orphan resolution) from TRIMMED (routine breathing — the SUCCESSOR_STATES false-secession fix).
7. **Cartography:** fill enclosed waste, close realm gaps, smooth borders — assertion bounded by remaining capacity headroom and forbidden from re-granting just-released tiles.
- **Flag derivation** (`adoptAndFound`): cities keep/found sovereignty (records bar; land nations materialise through their first city; SEAT_FIELD≥2 routes wilderness self-founding through the same stateless-basin test); villages adopt the grown owner of their ground, gated by the adopter's statecraft (ORG_STATE_MIN), or lapse (witnessed). `nucleateFrontierStates`: stateless basin ≥ `NUCLEATE_CLUSTER_POP(400 su)/lever × capacityMul(fert, disease, forest/iron, ÷rugged)` in field people (frozen-bridge exchange rate) with a basin-leading seat → new realm (≤4/pass); RESTORATION first — ground remembering one dead nation (⅔ supermajority of remembered weight, viable, kin-majority descent) re-opens that polity (name, hue, chronicle, buried treasury).

### 3.9 Politics / loyalty / secession / dynasties (conquest.js `updatePolities`, dynasties.js)
- **Capacity (Tilly):** `peaceCapacity = (CAP_K_REL·instMul·log2(1+capPower/refPower) + seatBonus≤cap·instMul) × dominance × …`, base power = governed-field population × capital mil·org anchored to the era median (POW_FIELD); dominance = saturating fiscal surplus per member vs the smoothed era mean × logistics (CAP_MODEL), ceiling rising with cohesion tech; imperial hysteresis stock (`_impCapacity` rises fast, decays 4× slower — durable Romes); × war duress (multifront, besieged/raided capital) × fiscal duress (solvency), eased by org resilience; + momentum (decaying conquest bank, doubled for nomads); × (1 + APPARATUS×works) — the works stock built from conquest loot vs the era median, √ law, dilapidating.
- **Admin load per member:** `(distance term ÷ holdRange, capped at SUBMIT_REACH for self-governing cities — the satrapy law) × sizeMul(log2 governed people) × recency × language friction ÷ coercion(√ armyAvailable vs province force incl. nationalist levy)`. Budget spent cheapest-first: covered provinces recover loyalty; over-budget bleed `LOYAL_DECAY×(1+over)×orgHold`; at loyalty 0 (and people detached under LOYAL_FIELD) → revolt seeds → `shedFrontier`/`shedPatch` (secession with viability, restoration of remembered nations, sub-realm blocs).
- **Unrest** = Σ grievances (hunger, conscription, war fatigue, over-tax, shocks, identity, old wounds from `_natGriev`, serfdom, slave share) − relief (peace, monuments legitimacy, ruler trait); ≥1 → rebellion (ravage + secede or capital riot). Serfdom/latifundia institutional stocks with the plague fork and tenure ratchet.
- **Consolidation channels:** submission (hopeless odds SUBMIT_RATIO=5 eased by momentum, hazard clock, identity/coalition brakes → vassal), unions of crowns, satrapization (mature suzerain integrates aged clients), peaceful absorption of weak neighbours (org-tier-gated), protectorates (naval submission beyond army reach), elite fracture (projected-power ambition, rival courts, magnate estates, succession crises → declareIndependence with vassal branch), colonial independence (dependency power ≥ 0.8× metropole's *projected* force), post-khan shatter, `fragmentRealm` (bounded successor count scaling with city count, recorded succession `succId`).
- **Loyalty field:** one owner-diff scan per polity pass stamps homeland/fell; `_allegiance` habituates toward the county's administrative condition at identity- and grievance-coupled rates; assimilation is attachment completing (replaces the flat memory timer); grievance ledger fed at harm sites (captures weighted by field people, sacks, razzias), decaying ~2 generations, ×3 faster between allies.
- **Dynasties:** sampled kin graphs per literate throne (org ≥ 0.22); once-at-birth lifespans (era-health-modified), marriages (foreign matches cluster within reach), births, bastards; succession by law (agnatic/male-pref/absolute) over the whole house with representation; failures → crises (legitimacy shocks, claimant wars via `_succClaims`, personal unions); government form emerges (theocracy/republic/monarchy); ruler traits modulate learning, order, war appetite; epithets from deeds. Runs on the separate uniform dyn clock (0.25 y/step, dt-weighted).

### 3.10 Culture / faith / identity
- **Cultures:** per-settlement mixtures (top-4); language is a separate living entity (drift, branching, borrowing). Assimilation toward the capital's prestige tongue at `0.05×org×dist` (ethnic identity at 0.1× that); divergence by overseas isolation (6000), political ethnogenesis (9000 under a durable language-shifted state), and **distance drift** past a cohesion radius (base 2% of map width + connectivity tech — stone age fragments, lingua francas consolidate); national standards for organized realms; trade convergence. Ancestry (`ancMix`) admixes only by migration — demographic blend/replace/bootload emerges from residence time + the settler disease barrier (malaria gap, asymmetric).
- **Faiths:** folk faiths per culture; organized genesis in an axial window (org ≥ 0.26, town ≥ 450, culture cooldowns); conversion by weighted pulls (state pressure 2.4, organized proselytism 2.2, folk 0.45, conformity consolidation 2.1); doctrine vectors (militancy…worldliness) bridging to realm temperament; schisms (span/age/distance-gated, bounded per root), rare syncretism, culls; loyalty nudges for shared/clashing creeds; pilgrimage economy (offerings flow to holy sees; dead sees of great faiths pull refounding).

### 3.11 Roads / sea lanes
- **Roads:** pure per-tile quality/flow fields. Planning every 240: link close neighbours (Gabriel-graph test), build only bridging or genuine-shortcut segments (A* `findPath` with land-component oracle), painted at the builder's roadcraft; flow from active trade paves toward floors gated by the owning realm's Roads/Railroad techs; idle roads decay away. Trade reach = per-settlement Dijkstra through road/river/coast tiles (visit-capped, ≤12 partners), staggered over 120 ticks.
- **Sea (every 600):** one multi-source ocean flood from all ports (nav-gated range: paddle 2.0 → tech ladder; wind-aligned costs, ice); lane graph + transitive closure → `_seaReach` peers (bounded, value-ranked: gravity + luxury sourcing − freight); colony ships (visible entities, per-tick movement) from ports (pop/nav/cooldown/personality-gated) to surveyed shores ≥14rn from anyone, or **chartered** by realms (treasury endowment, org ≥ 0.6, land-hunger pressure popField/capField ≥ 0.7, or a luxury quest to known source regions); landing founds a colony wired as a dependency (`_overlordCC` → polity `_overlord`, colonial economy: investment while young, tribute when mature, tech transfer × reach).

**Redesign (entangled with the entity model, or accreted dual systems):**

A v2 should have ONE cost field and two thin queries (market assignment; admin distance) over it — most of the patch tissue (CATCH_GRACE, MARKET_FARM_HOLD, SEED_EXCLUSIVE, CITY_HOLD, rel/relCut) exists only because the two recompute at different cadences over each other.
- **Founding/dissolution (`crystallize.js`).** The site lane + bars are keepers, but the file carries the retired sweep, three label-supply generations kept as "instruments", TOWN_BASIN_R serving six unrelated questions (its own comment documents this), and the peer/land-nation/fission lanes re-implementing the same basin exam thrice. Redesign around one founding exam (basin mass × bad-year margin × storable × tally) invoked by every lane.
- **`conquest.js updatePolities`.** The capacity model is a tower of anchored ratios (median power, median revenue, works ruler, hysteresis stock, dominance, duress, momentum, apparatus) each patching the last's failure mode; several dead lever arms survive as comments. The *concepts* (capacity vs load, cheapest-first coverage, loyalty stocks, elite fracture, submission/coalition brakes) validate well and should port as design, but re-derived on one power unit (governed field people) rather than five bridged rulers.
- **foodHierarchy tree topology.** The liege-tree levy is historically motivated but the tree itself is a stale artifact of buildHierarchy (same-country only, staleness roots); the open market + MARKET_PULL bid already do the real work. v2: one market clearing over the reach graph, with the levy as an institution modifier — not a second topology.
- **armies.js adapter layer.** TILE_WAR drives settlement-shaped "adapter" objects through per-settlement code; casualty reconciliation back to garrisons is fragile bookkeeping. v2 should be country-native from the start.
- **Worker snapshot protocol** — functional but hand-rolled per-lens; regenerate from a declarative overlay registry.
- Tuning surface: ~350 levers, many shipped-at-0 refuted experiments retained for save-compat; a v2 reset can cull to the ~40 live physical constants (each with its independent meaning per cardinal rule 2).

## 6. DETERMINISM

- **RNG discipline (`rng.js`):** no shared sequential stream, ever (state.js explicitly: "NO shared world.rng"). Every consumer derives sfc32 from `hash32(seed, systemName, step)` (`passRng`) or `(seed, systemName, entityId)` (`entityRng`); many gates use raw `hash32(...)/2^32` one-shot rolls keyed on (seed, name, id, step). Streams are stateless across ticks ⇒ **no RNG state in saves**; adding a consumer never perturbs existing draws. - **Ordering:** fixed iteration orders everywhere (settlements in array order; Maps iterated in insertion order with sorted-key hashing; `[...keys].sort` before any order-sensitive fold); stable sorts with explicit id/index tiebreaks (bid hysteresis, shed "most remote first (index tiebreak)", GRAIN_BID `(price)||(id)`, site quantizer `(v)||(x)||(y)`, watershed plateau "lowest index"); scan-then-apply for order-independence (VASSAL_LEVY levies off pre-levy strengths); double-buffered relaxations (popField migration, devField wave — an in-place sweep would give infinite wave speed); first-pop-finalize Dijkstra with stamp arrays; spatial-grid updates (`gridAdd`) so same-pass candidates see earlier mints.
